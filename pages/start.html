はじめに（ワールドの準備）

保護者の方が、お子さんと一緒に最初に一度だけ行う準備です。所要時間は20〜30分ほどです。画面の項目名は Switch 版の表示に合わせて書いていますが、未確認のものには【要実機確認】を付けています。実際に確かめたら、実機チェックリストに記録してください。

最初に：大事なワールドは使わない

お子さんはオンラインで遊んでいて、大事なワールドがあると伺っています。コマンドの練習は、練習用に新しく作ったワールドだけで行ってください。チートを ON にしたワールドでは実績（トロフィー）が解除されなくなり、OFF に戻しても元に戻りません。

1. 大事なワールドの控えを作る（念のため）

  1. タイトル画面で「遊ぶ」を選ぶ。
  2. 大事なワールドの横の鉛筆（編集）ボタンを押す。【要実機確認】
  3. 「ワールドをコピー」を選ぶ。【要実機確認】
  4. 「（コピー）」付きのワールドが一覧に増えたことを確認する。

控えは「元のワールドに何かあったときに戻すため」のものです。控えのほうでもコマンド練習はしないでください。

2. 練習用ワールドを作る

  1. 「遊ぶ」→「新しく作成」→「新しいワールドを作成」を選ぶ。【要実機確認】
  2. ワールド名を「コマンドれんしゅう」などにする。
  3. ゲームモードを「クリエイティブ」にする。
  4. ワールドタイプは「フラット」にすると平らで装置を作りやすい。【要実機確認】
  5. 「チート」を ON にする。実績が無効になる確認が出たら「続ける」。【要実機確認】
  6. 同じ画面で「座標を表示」を ON にする（レベル2で使います）。【要実機確認】
  7. マルチプレイの設定で、オンラインに公開しない（フレンドが参加できない）設定にする。【要実機確認】
  8. 「作成」を押す。

3. チャットを開いてコマンドを打つ

  1. ゲーム中に、十字ボタンの右（→）を押すとチャット画面が開く。【要実機確認】
  2. 入力欄を選ぶと画面キーボードが出る。携帯モードでは指で直接タップできる見込み。【要実機確認】
  3. キーボードを英数入力に切り替え、/time set day と打って送信する。
  4. 朝になれば成功です。

4. コマンドブロックを手に入れる

コマンドブロックはクリエイティブのインベントリには出てきません。チャットで次のコマンドを打ちます。

  • コマンドブロックを置いて設定するには、オペレーター権限とクリエイティブモードが必要です。自分で作ったワールドなら、作った人はオペレーターです。
  • 置いたコマンドブロックに向かって ZL ボタン（使う／置くボタン）を押すと設定画面が開きます。【要実機確認】

5. コマンドブロックのログを止める

レベル5でリピートのコマンドブロックを使うと、チャットに実行結果が大量に流れます。先に次を打っておくと静かになります。

6. タブレットの準備

  • Android タブレットの Chrome でこのサイトを開き、メニューの「ホーム画面に追加」でアイコンを作っておくと、お子さんが一人で開けます。
  • 作り方のページでは、画面が自動で消えないようにしています（Screen Wake Lock API）。それでも消える場合は、Android の「設定」→「ディスプレイ」→「画面消灯」の時間を長くしてください（メニュー名は機種で異なります）。
  • 「よみあげ」ボタンは、端末に日本語の音声が入っていると使えます。読まれない場合は、Android の「設定」→「システム」→「言語と入力」→「テキスト読み上げ」で日本語の音声データを入れてください（メニュー名は機種で異なります）。

7. 安全の約束をお子さんと確認する

「やっては いけない コマンド」のページを一緒に読んでください。特に「友だちのワールドでは打たない」「/ を忘れるとチャットとしてみんなに送られる」の2点です。
